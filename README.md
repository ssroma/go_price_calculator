# Price Calculator

A simple Go application for a price calculator project. This starter project sets up the basic module and entry point, and it is ready to be expanded with pricing logic such as totals, discounts, tax calculations, or itemized products.

## Project Overview

This project currently contains:

- `main.go` as the application entry point
- `go.mod` for Go module configuration

The app currently prints a basic startup message:

```bash
Price Calculator App
```

## Prerequisites

Before running the project, make sure you have Go installed on your machine.

- Go 1.22+
- A terminal or command prompt

## Run the Application

From the project root, run:

```bash
go run .
```

Example output:

```bash
Price Calculator App
```
